# Bacancy EHR Overview


## The problem
Many clinics run scheduling, prescriptions, video visits and lab orders in separate tools. Staff re-type the same patient details several times a day. Each re-typed field is a chance for an error.


## What Bacancy EHR does
Bacancy EHR puts these workflows in one patient record. A booking creates the chart. The clinician prescribes, consults and orders labs from that chart. Results come back to the same place.


## Who uses it
| Role | What they do in Bacancy EHR |
|---|---|
| Front desk | Book appointments, register patients, check in visits |
| Physician | Review the chart, consult in person or by video, prescribe, order labs |
| Nurse | Record vitals, review RPM readings, prepare visits |
| Pharmacist | Receive e-prescriptions |
| Practice manager | View schedules, users and reports |
| Admin | Set up users, roles and integrations |


## What changes for the practice
One patient record instead of several disconnected tools
Less re-typing between the front desk, clinicians, labs and pharmacies
Standards-based data exchange through FHIR R4 and HL7

# Bacancy EHR Features


## Front Desk
### Patient Scheduling
Book, reschedule and cancel appointments for each provider and location. See the full day on one calendar.


### Patient Registration
Create the patient record once at booking. Every later visit, prescription and result is added to that record.


## Clinical
### Patient Chart
See history, visits, prescriptions, lab results and device readings in one view.


### E-Prescriptions
Write a prescription from the chart and send it to the patient's pharmacy electronically.


### Teleconsultation
Start a video visit from the appointment. Notes from the visit are saved to the chart.


### Remote Patient Monitoring (RPM)
Readings from connected devices appear in the chart, so the care team can review them between visits.


## Orders and Results
### Lab Integration
Send lab orders and receive results into the chart.


### Pharmacy Integration
Send prescriptions to the pharmacy and track their status.


## Admin
### Users and Roles
Give each person access only to what their role needs.


### Integrations Setup
Connect other EHRs, labs and pharmacies through FHIR R4 and HL7. See [integrations](integrations.md).
