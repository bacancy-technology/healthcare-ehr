# Bacancy EHR Overview

Bacancy EHR is an electronic health record for clinics. It keeps scheduling, the patient chart, e-prescriptions, teleconsultation, remote patient monitoring, and lab and pharmacy orders in one patient record.

## Who uses it
| Role | What they do in Bacancy EHR |
|---|---|
| Front desk | Book appointments, register patients, check in visits |
| Physician | Review the chart, consult in person or by video, prescribe, order labs |
| Nurse | Record vitals, review RPM readings, prepare visits |
| Pharmacist | Receive e-prescriptions |
| Admin | Set up users, roles and integrations |

## Modules
- Scheduling and registration
- Patient chart
- E-prescriptions
- Teleconsultation
- Remote patient monitoring (RPM)
- Lab and pharmacy integration
- Users, roles and integrations setup
