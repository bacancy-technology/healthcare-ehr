# Super Admin Panel Guide

## What admins can do
Run clinic operations from one place.

## Main areas
- **Finance and revenue:** payments, claims and revenue reports.
- **Quality and triage:** quality tracking and triage queues.
- **AI escalations:** review cases the AI sends to staff.
- **Partner approvals:** approve or reject lab and pharmacy registrations.
- **Users and access:** set role-based access for staff.
