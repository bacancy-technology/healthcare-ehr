# Admin Guide


## What you do in Bacancy EHR
Set up users, roles, locations and integrations.


## Add a user
1. Open **Admin → Users → New user**.
2. Enter the name and email.
3. Choose a role.
4. Click **Save**. The user gets an email invitation.


## Connect an integration
1. Open **Admin → Integrations**.
2. Choose the system type: FHIR, HL7, lab or pharmacy.
3. Enter the connection details from your integration partner.
4. Click **Test connection**, then **Save**.
