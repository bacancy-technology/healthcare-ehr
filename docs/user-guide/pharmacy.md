## Joining the network
Register with licence verification. The pharmacy goes live after admin approval.

## Daily workflow
1. Receive prescription orders.
2. Move each order through: New → Accepted → Preparing → Ready → Out for delivery → Completed.
3. Choose pickup or delivery. Delivery is priced by distance.
4. Keep inventory up to date.
